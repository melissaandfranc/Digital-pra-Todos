# Digital para Todos

Projeto da faculdade (Análise e Desenvolvimento de Sistemas, 2º semestre).

## Temas
- Impacto social da tecnologia
- Inclusão digital e acessibilidade

## Ideia
Um site com duas ferramentas:
- **Tradutor de tecniquês:** explica Pix, gov.br, WhatsApp e golpes em linguagem simples, para quem tem pouca familiaridade com o digital.
- **Avaliador de acessibilidade:** analisa um trecho de HTML e aponta barreiras para pessoas com deficiência, com sugestões de correção.
